# BROMAX's Exofall

A Minecraft 1.21.1 NeoForge RPG mod. Huge procedurally generated meteors lie half-buried across the Overworld. Each one is a self-contained biome with its own stone, woods, plants, insect mobs, sub-structures, bosses and legendary gear.

Breaking through a meteor's crust takes a pickaxe forged from late-game materials (nether stars, echo shards, netherite). The gear inside starts around Netherite level and goes well beyond it. Powerful armour and weapons are made at a 5x5 crafting table from dungeon loot.

Built for the late game of the **Sovereign 202** modpack, but it works on its own. Gear power can be scaled in the config.

**Status:** early development. Nothing playable yet.

## Credits
Inspired by **The Erebus** by vadis365 and team. Exofall is an original mod: no Erebus code, assets or names are used.

## Building
```bash
./gradlew build     # jar in build/libs/
./gradlew deploy    # build + copy into the "Exofall testing" CurseForge instance (-PdeployInstance=... to change)
```
Requires Java 21.
